## Notre organisation GitHub

Cet espace rassemble les projets logiciels développés et maintenus dans le contexte de l'**Institut universitaire de technologie (IUT) de Troyes**, composante de l'**Université de Reims Champagne-Ardenne (URCA)**.

Il facilite le partage du code, la documentation des applications, le suivi des évolutions et le travail collaboratif.

## Projet à découvrir

### [uniServices](https://github.com/IUTTroyes/uniServices)

**Une plateforme modulaire de services universitaires**, conçue pour faire évoluer l'intranet et rassembler plusieurs applications au sein d'un environnement cohérent.

| Domaine | Description |
| :-- | :-- |
| **Intranet** | Accès aux informations et services de l'établissement. |
| **Authentification** | Fonctionnalités de connexion et de gestion des accès. |
| **Emplois du temps** | Module dédié aux emplois du temps. |
| **Architecture modulaire** | Applications organisées en bundles indépendants et composants mutualisés. |
| **Expérience utilisateur** | Interfaces modernisées et ressources frontend partagées. |

Le dépôt comprend le code source, la documentation technique, les instructions d'installation et les conventions de développement.

[**Accéder à uniServices**](https://github.com/IUTTroyes/uniServices) · [**Consulter les issues**](https://github.com/IUTTroyes/uniServices/issues) · [**Proposer une contribution**](https://github.com/IUTTroyes/uniServices/pulls)

## Technologies

Le projet uniServices utilise notamment :

- **Backend :** PHP, Symfony, Doctrine et API Platform.
- **Frontend :** Vue.js, Vite, Tailwind CSS, Pinia et PrimeVue.
- **Outillage :** pnpm, Docker, PHPUnit, Vitest et Cypress.

Les versions et prérequis à jour sont précisés dans le [README technique de uniServices](https://github.com/IUTTroyes/uniServices#readme).
